# Naming & placement rules

* **Kebab-case** for files/dirs; two-digit section prefixes for ordered docs (e.g., `010-…`).
* **Tasks** live under `tasks/NNN-slug/`; NNN is monotonically increasing (three digits).
* **ADRs** use a 4-digit counter: `adr/0001-title.md`.
* **Brainstorms** live only under `brainstorms/` and are **gitignored** and **excluded from agent context**.
* Narrative docs = **Markdown**; machine-checkable truth = **CUE** under `schemas/` and each task’s `task.cue` / `acceptance.cue`.

# Typed vs prose (minimal contract)

| Artifact                    | Form     | Source of truth (typed)                | Notes                                            |
| --------------------------- | -------- | -------------------------------------- | ------------------------------------------------ |
| Architecture docs (project) | Markdown | `schemas/project.cue` (stack, budgets) | Human-readable narrative; typed for tooling.     |
| Roadmap                     | Markdown | *(optional typed later)*               | High-level guidance; not a requirements doc.     |
| Guidelines                  | Markdown | *(can import external style repos)*    | Project rules & curated patterns.                |
| PRD (feature-only)          | Markdown | `schemas/work_item.cue` fields         | PRD front-matter is implied by `task.cue`.       |
| Work item manifest (task)   | CUE      | `task.cue`                             | Type, scope, links, acceptance, traceability.    |
| Acceptance criteria         | CUE      | `acceptance.cue`                       | CI enforces presence + basic shape.              |
| ADR                         | Markdown | *(optional small CUE index)*           | Created post-ideation for significant decisions. |
| Brainstorms                 | Markdown | —                                      | Temporary; auto-cleanable; out of agent context. |
| Context policy              | CUE      | `context/include.cue`                  | Which files the agent may read per phase.        |

### 12) `ci/workflow-example.yml` (CI blueprint)

```yaml
name: Forge Validate
on:
  pull_request:
jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Ensure no brainstorm files in PR
        run: |
          if git diff --name-only origin/${{ github.base_ref }}... | grep '^\.forge/ai/brainstorms/'; then
            echo "Brainstorm files must not be committed."; exit 1; fi
      - name: Install cue
        run: sudo bash -lc "curl -L https://github.com/cue-lang/cue/releases/latest/download/cue_$(uname -s)_$(uname -m).tar.gz | tar -xz -C /usr/local/bin cue"
      - name: Validate schemas
        run: |
          cue vet .forge/ai/tasks/*/task.cue .forge/ai/schemas/work_item.cue
          cue vet .forge/ai/tasks/*/acceptance.cue .forge/ai/schemas/acceptance.cue
      - name: Lint docs exist for changes (basic)
        run: |
          CHANGED=$(git diff --name-only origin/${{ github.base_ref }}...)
          if echo "$CHANGED" | grep -E '^(cmd/|pkg/|src/|app/)' >/dev/null; then
            test -n "$(ls .forge/ai/tasks/*/prd.md 2>/dev/null)" || { echo "PRD missing for code changes"; exit 1; }
          fi
```

## Implementation notes

* **Persistence across agents:** brainstorm files live at `/.forge/ai/brainstorms/…` so Claude Code, Cursor, Gemini CLI can all read them locally; they’re **not** committed and **not** in default context once you move to spec/plan.
* **Task vs feature:** we standardize on **task** with `type:` enum in `task.cue` (`feature|refactor|perf|bug|docs|ci`).
* **Separation of concerns:** narrative MD is for humans; **CUE** holds machine-checkable metadata (work item manifest, acceptance, context rules). CI only needs `cue vet` + a couple of shell checks to enforce 80% of the rules on day one.
